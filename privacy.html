Política de Privacidade

Última atualização: 28 de agosto de 2026

O canais-pipeline é uma ferramenta interna, desenvolvida e operada pela ClickWeb, usada para produzir e publicar vídeos curtos nos próprios canais de YouTube e TikTok que a ClickWeb administra (atualmente: Seguro Não Morre De Velho, Bugadinho 4K, Verbo & Oração e Pulse & Motion). Não é um serviço público, não tem cadastro de usuários e não é oferecido a terceiros — só a equipe da ClickWeb o executa, na própria máquina, conectando as próprias contas.

Quem opera o app e quem é o titular dos dados

O app é executado localmente pelo operador (funcionário/colaborador autorizado da ClickWeb). Os "dados" tratados por ele são as próprias contas de YouTube/TikTok que o operador conecta — não há coleta de dados de visitantes, espectadores ou qualquer pessoa além do próprio operador.

Dados acessados via YouTube (Google)

Ao conectar um canal do YouTube, o app usa a YouTube Data API v3 e a YouTube Analytics API, com os seguintes escopos OAuth:

EscopoPara que é usado
youtube.uploadSubir os vídeos produzidos, sempre como privados.
youtube.force-sslEditar metadados (título/descrição) de vídeos já publicados pelo próprio app, quando necessário corrigir algo.
youtube.readonlyLer informações básicas do canal conectado.
yt-analytics.readonlyLer estatísticas de desempenho (visualizações, retenção, inscritos) dos vídeos publicados pelo próprio app, exibidas na aba "Analytics" do app.

Este app usa a YouTube API Services. Ao usá-lo, o operador concorda com os Termos de Serviço do YouTube e reconhece a Política de Privacidade do Google.

Dados acessados via TikTok

Ao conectar uma conta do TikTok, o app usa a Content Posting API oficial do TikTok, com os seguintes escopos:

EscopoPara que é usado
user.info.basicLer informações básicas do perfil da conta conectada (nome de exibição, foto, ID da conta) e os limites de publicação/privacidade permitidos pra essa conta.
video.publishPublicar vídeos em nome dessa mesma conta, a pedido do operador.

Enquanto o app não passa pela auditoria de conteúdo do TikTok, todo vídeo publicado sai visível só para a própria conta (SELF_ONLY) — restrição imposta pelo TikTok, não uma escolha do app.

Não coletamos dados de espectadores, seguidores ou qualquer conta do TikTok que não seja a conta explicitamente conectada pelo operador.

Outros serviços de terceiros usados na produção

  • Modelo de linguagem (ChatGPT): usado, via a sessão web do próprio operador (login manual, sessão local persistida), só para escrever/traduzir o texto de cada vídeo. Nenhuma credencial de API é enviada; a automação só interage com a página como um navegador comum faria.
  • Pexels: banco de imagens/vídeos royalty-free, usado para buscar clipes de fundo via a chave de API pessoal do operador.
  • Fontes públicas de vídeo (Bilibili e afins, canal Pulse & Motion): o app busca e baixa clipes públicos pra recortar/curar, sem autenticação nem coleta de dados pessoais dessas plataformas.

Como e onde os dados são armazenados

Os tokens de acesso (OAuth) do YouTube e do TikTok, o histórico de vídeos produzidos e as configurações do app ficam salvos localmente, no computador onde o app roda. Não há servidor próprio, banco de dados remoto, nem qualquer envio desses dados para a ClickWeb ou para terceiros além das próprias APIs (Google/YouTube, TikTok, Pexels) usadas para executar a ação pedida pelo operador. Não vendemos, compartilhamos nem usamos esses dados para publicidade ou para treinar modelos de terceiros.

Retenção e revogação

Os tokens permanecem salvos localmente até que o operador desconecte a conta pelo próprio app, ou revogue o acesso diretamente nas configurações da conta Google ("Segurança → Apps de terceiros com acesso à conta") ou do TikTok ("Configurações → Apps e Serviços Conectados"). Ao revogar, o app perde o acesso imediatamente na próxima tentativa de uso.

Exclusão de dados

Como todos os dados ficam só na máquina local do operador, a exclusão é imediata: basta desconectar a conta pelo app (ou apagar a pasta de dados do app) e/ou revogar o acesso diretamente no Google/TikTok, como descrito acima. Pedidos de esclarecimento podem ser enviados para o contato abaixo.
